METHODOLOGY:
 - 1. Development vs confirmation (threat 3). Call the 21 variants plus seed sets 42/7/13 and 101/202/303 the development benchmark, freeze the configuration after the E39 decision, and pre-register one confirmation read. It covers the 14 untouched on-disk variants (pendigits/letter/electricity 40/60/80nan, vehicle/biodeg/kc2 40/80nan), 2-3 new OpenML tables, an optional second MCAR draw per small table written to a new suffix (generate_splits.py:202 overwrites in place, so never regenerate into datasets/processed_datasets), and never-used seeds. Before reading it, fix the ADR 0018 inheritance rule for the 40-80nan rungs and add the context-free-row share. Read it once, for the headline.
 - 2. Statistics (threats 1 and 6). Use paired per-fold model-minus-opponent differences on shared folds. The primary claim about the method is cross-table: Wilcoxon signed-rank or a Bayesian signed-rank test (Benavoli et al. 2016) over tables, with Holm across opponents, over 9 tables now and more with the confirmation tables. Report per-variant tallies better / no difference / worse under the project rule as descriptive results, with a seed random-effects column as sensitivity. Report both seed sets, name the test beside every count, and drop 'N of 21 by means'. Pre-register a SESOI of about 1% relative and read 'worse on none' vetoes as equivalence tests.
 - 3. Equal tuning budgets (threat 2). Give each baseline family a declared validation-only selection equal in kind to the model's: KNN k in {5,10,20,50}; hgb/lgbm over about 12 configs of lr x max_iter x depth/leaves x min_samples_leaf; missForest mtry and trees; a mean-shrinkage alpha for the 60-80nan rungs. Select per fold on the same validation signal the model uses, refit on train plus validation, and log the chosen settings. The model gets no new tuning on the confirmation set. Keep the untuned bar as a secondary row so continuity with ADR 0007 stays visible.
 - 4. Symmetric, deployable selection (threat 4). The headline arm for any claim that must transfer to natural or clinical data uses a checkpoint criterion that needs no gap truth: H, or a masked lambda-free per-epoch impute_score. Report K beside it as an oracle upper bound. If K stays the RQ1 headline, give baselines a validation-gap selection of equal strength. Every RQ2/RQ4 arm uses the deployable criterion.
 - 5. Opponent set (threat 1). Report each claim against three opponents: the plain-imputer bar of 5, missForest with ADR 0016's ±0.016 inductive caveat, and the best of all six. The dedicated imputers RQ1 names (ReMasker, CACTI, DiffPuter, TabImpute) are the eventual primary comparison and should go through the same protocol.
 - 6. Metric suite (threats 5 and 8). Keep impute_score as primary. The pre-registered secondary panel: per-kind RMSE ratio, per-kind MAE ratio, accuracy ratio, balanced-accuracy ratio (preferred over macro-F1, which rare-label noise inflates), column-normalised numeric ratio for heavy-tailed tables, per-column signed bias, dispersion ratio and 1-D Wasserstein for numerics, category-frequency total variation, a twin/no-twin split on kc2/letter/spambase, and downstream utility (classify on data imputed by each method vs the complete _00nan sibling). Claim only where the primary and per-kind readings agree; list disagreements.
 - 7. MNAR arms (threat 5, mnar-blind-score). Report raw error and signed bias against the complete truth beside the ratio, plus an MCAR/MAR control sample at equal rate. Under MNAR the ratio stays honest only on the masked population. On the induced population an equally biased imputer moves toward 1, and an imputer that removes bias drops below its MCAR value while its absolute error can grow. Never select checkpoints on MNAR-shifted truth.
 - 8. Search hygiene (threat 7). Use validation-only objectives for both tasks. Use disjoint validation cells for the checkpoint and the objective (T08) and inner repeats (T09). Promote a file only if it beats the no-file default (D) on seeds and rows the study never saw, and log that comparison in the ADR.
 - 9. Cross-level and population readings (threat 9). State dose-response only within table or with table fixed effects, never read the masked population across levels, and complete the cheap ladders (vehicle, biodeg, kc2 at 40/80nan) if a level trend becomes a thesis claim.
 - 10. Classification step zero (classification_notes). Run it on 80/10/10-shaped splits (--cv_folds 10), with an upstream 40/40 arm and a fork 300/150 arm. Tune on validation macro-F1 at the kept checkpoint with the baselines' budget. Pool across tables per missingness level with the seed-sign rule.
